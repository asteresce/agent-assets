# Shared skills catalog

These skills are provider-neutral. Consumers import them and adapt them for their agent.

Each skill is a directory containing a `SKILLS.md` file and any artifacts it needs. A skill can be referenced in a config by its directory name.

| Skill | Description | Suggested frontmatter |
|---|---|---|
| [`migration/`](migration/SKILLS.md) | Guide for performing structured migrations. | `owner`, `language` |

Add new skills here as directories and document them in this file.
